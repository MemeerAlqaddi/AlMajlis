AUTOMATED REVIEW
Run these from the package root:

  npm install
  npm run audit:content:strict
  npm test
  npm run build

The strict audit checks deck counts, IDs, exact and near duplicates, Riddle
answer uniqueness, wording heuristics, source format, Qur'anic reference bounds,
Guess the Word clue counts, and Complete the Ayah continuation length.
